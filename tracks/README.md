# Your own music

Put music files here (m4a, mp3, wav, aac, flac or ogg) and push. They're published with the web version,
which loads them by itself on every laptop, so there's no need to choose a music folder.

- **Everything here is public.** Anyone can download these files from the site or the repository.
  Only add music you made yourself or have permission to share. Never add ADF, band or commercial
  recordings.
- Name files the way Muster likes: `12 Name of the March.m4a`. The number sets the order.
  Words like "march", "salute", "drum" or "hymn" pick the category, and you can change it later on the
  Music page.
- GitHub limits each file to 100 MB, and the whole site should stay under 1 GB.
- Each laptop downloads a track the first time it's played or analysed, then keeps a copy for offline use.
